手绘图形 Rough

使用说明与功能入口

面向 PowerPoint 的原生可编辑手绘图形、科研绘图、论文预设、特征块、素材和论文图像工作台。

一、快速开始

  1. 打开入口。在 PowerPoint Ribbon 中打开“手绘图形 Rough”选项卡；需要精确参数或资源管理时，再打开右侧任务窗格。
  2. 插入或转换。新建对象用 Ribbon 的形状图库；已有 PowerPoint 形状用“转换手绘”。
  3. 选中后调整。选中普通形状或手绘组后，简洁模式会自动显示当前可用的风格工作区；未选中对象时不会显示参数调整功能。
  4. 改完即重绘。右侧参数和 Ribbon 风格菜单都会同步到选中的手绘对象并触发重绘；需要重新生成边界时也可用 Ribbon 的“重绘选区”。
  5. 保存复用。常用对象可保存到“我的素材”，常用形状可固定到“快速插入”。
边看边操作：从插件右上角打开时，使用说明会显示在独立非模态窗口中，不会替换右侧任务窗格。说明窗口保持打开时，仍可继续点击 Ribbon、选择对象并实时尝试功能。
对象原则：手绘图形、特征块和科研图表最终均为 PowerPoint 原生可编辑对象，可继续拖动、缩放、旋转、改文字、对齐和调整层级。Zotero 论文参考图像是唯一图片例外。

二、功能入口总览

Ribbon 只保留“常用、快速插入、风格、论文与特征、素材”五组。少于 5 项的固定功能直接排列，只有至少 5 项的集合使用下拉菜单；右侧任务窗格负责参数、预览、搜索和完整资源管理。

  • 常用：形状图库、转换手绘、重绘选区、选择载体、检查选区、功能搜索和右侧窗格。
  • 快速插入：直接显示已固定的常用形状，并提供一个管理入口。
  • 风格：风格模板、组合样式、填充和线条。
  • 论文与特征：论文套件、二维/三维/手绘特征、常用预设、方向调整和保存默认。
  • 素材：保存素材、最近素材、刷新、导入、分享，以及打开 Zotero 生成的完整论文图片库。

简洁模式与完整模式

  • 简洁模式：根据无选区、普通对象、手绘组或特征块选区，只显示当前可用工作区。
  • 完整模式：显示全部专业面板，用于跨功能浏览、资源管理和高级参数设置。
  • 定位入口：搜索结果和 Ribbon 的“打开窗格”类入口只定位到功能，不会直接执行删除、导入、转换或重绘。
流式布局：任务窗格的顶栏、工作区、面板、工具栏、筛选组和操作按钮统一使用 flex/grid 流式布局。拖动改变窗格宽度时，控件会按可用空间自动填充和换行；按钮文字保持完整横排，不会互相覆盖或被截断。

三、插入与管理手绘图形

插入新形状

  1. 打开 Ribbon 的“手绘图形 Rough”选项卡。
  2. 从形状图库按类别选择形状，或使用直线、箭头、矩形、椭圆等常用入口。
  3. 插件按当前风格在幻灯片中插入 PowerPoint 原生对象组。

转换已有对象

  1. 在幻灯片中选择一个或多个普通 PowerPoint 形状。
  2. 点击 Ribbon“转换手绘”。已是手绘组的对象会自动跳过。
  3. 转换后可在右侧“风格”中精调，再用“重绘选区”更新边界。

当前选区操作

重绘选区
按对象当前尺寸、调整点和风格参数重新生成手绘视觉，不新建幽灵对象。
选择载体
选中手绘组内隐藏的原生载体，便于使用 PowerPoint 调整点改变圆角、箭头等几何，再执行重绘。
检查选区
查看原生对象、图层角色和重绘元数据，用于确认对象类型和定位异常。
保存素材
把当前选中的 PowerPoint 原生对象保存到本机素材库，之后可跨演示文稿插入。

快速插入

右侧完整形状浏览可把常用形状固定到快速插入栏。Ribbon 可直接插入固定形状，也可从管理菜单移除固定项；移除不会删除幻灯片中的已有对象。

四、风格、模板与实时重绘

选中普通对象或手绘组后，简洁模式自动进入风格工作区。模板用于整组参数，手动改任一参数后会退出模板选中态，避免误以为仍在使用完整模板。

风格模板

轻微手绘、论文框图、粗线草图等预置模板可直接应用。自定义模板支持保存和重命名。

边界与扰动

线宽、粗糙度、弯曲度、随机种子、普通边界、二层或三层嵌套、嵌套错位方向。

填充

无填充、纯色、白底、涂刷、斜线、交叉、点状、短划和锯齿等；权威填充仍由原生闭合边界承载。

线条与箭头

实线、虚线、点线、点划线，细线到粗线，以及无箭头、单向、双向和多种箭头头型。选中“手绘箭头”后，“线条”参数组会显示三角形长度和宽度滑杆，可分别控制箭头沿线长度与垂直宽度。

视觉来源

可分别选择 Rough.js、Excalidraw、draw.io、D2、tldraw 等边界或填充来源，再继续精调。

实时更新

选中手绘组时，右侧参数和 Ribbon 风格、填充、线条快捷项都会立即重绘当前选区，不会只影响后续插入。若先用 PowerPoint 调整点改变圆角或箭头载体几何，请点击 Ribbon“重绘选区”重新生成边界。

单独调整手绘箭头三角形

  1. 在幻灯片中选中手绘箭头组，打开右侧“风格”并展开“线条”。未选中手绘对象时，参数区不会显示。
  2. 将“箭头”设为“手绘箭头”。“箭头长度”控制沿线方向的三角形长度，范围 4 至 40 磅，默认 14 磅；“箭头宽度”控制垂直方向宽度，范围 4 至 32 磅，默认 10 磅。
  3. 拖动任一滑杆即可实时重绘当前选区。短线会自动限制箭头长度，避免三角形超过线段；长度和宽度互不覆盖。

Ribbon 的风格模板同样会同步重绘已选中的手绘对象；未选中可重绘对象时，只更新后续插入和当前面板参数。

五、二维与三维特征块

特征块适合表示卷积特征图、图像 Patch、张量、体数据、注意力图和中间层表示。Ribbon 提供高频预设，右侧提供完整参数和方向编辑。

  • 模式与数量：二维或三维、横向 X、纵向 Y、深度 Z。
  • 尺寸与结构：块宽、块高、块深、间距和圆角。
  • 视觉：普通或手绘模式、边线、起止颜色、渐变方向。
  • 方向编辑：左、右、上、下、前、后分别增加或删除一列、一行或一层。
  • 预设：二维 3×3、三维 3×3×3、手绘二维、手绘三维、长条特征、注意力图、体数据块等。
  • 默认参数：当前配置可保存为默认；再次插入时复用。

六、科研绘图

科研绘图把实验聚合结果转换为 PowerPoint 原生线、形状、文字和表格。独立工作区使用本地 Papa Parse 读取 CSV，并使用本地 Chart.js 切换预览；预览不会作为图片插入。旧任务窗格导入面板继续处理统计 JSON、论文表格和自动化结果。

标准流程

  1. 点击右侧“科研绘图”，在独立工作区选择一个 CSV；也可先加载示例检查预览。
  2. 选择横轴或标签、数值、可选分组和误差字段。
  3. 在柱状图、折线图、散点图、分组对比、均值误差图、病例分布和结果表格之间切换预览。
  4. 确认标题和图表类型后点击“插入 PPT”。需要导入 JSON、Markdown、文件夹或 SimpleExperiment 聚合结果时，继续使用旧任务窗格导入面板。
  5. 插入后可用 PowerPoint 原生方式继续编辑每个元素。

支持的结果入口

  • SIMPLEEXPERIMENT 项目中的 statistics.json 和论文结果表 CSV。
  • 常见 JSON、CSV、Markdown 摘要及其同名结构化结果。
  • SIMPLEEXPERIMENT 本机自动化接口发送的绘图请求。

七、论文套件与结构预设

论文套件用于快速生成可编辑框图骨架。Ribbon 放高频一键预设，右侧提供搜索、分类、收藏和大面积预览。

  • 论文节点、数据节点、判断节点、分组虚线、高亮框和粗箭头
  • Transformer 编码器与解码器、视觉编码器、文本编码器、多模态融合
  • 对比学习双塔、注意力机制、Q-Former、VLM、RAG 和大模型诊断流程
  • 医学分割、报告生成、临床验证、联邦学习、生存分析和主动学习
  • MoE 专家路由、纵向随访、弱监督 MIL、知识图谱、教师学生蒸馏
  • 论文矩阵、体数据块、注意力图和诊断评估面板

预设插入的是 PowerPoint 原生组，文字、颜色、尺寸和连线均可继续修改。预览仅用于选择，不会把预览图作为最终对象插入。

八、素材、论文图像与配色

我的素材

  • 保存当前选区，保留 PowerPoint 原生对象结构。
  • 按名称搜索、插入、重命名、删除、批量选择和刷新。
  • 通过安全分享包导出或导入选定素材；导入时自动按原生 PPT 模板内容检测重复，跳过已有素材和包内重复项，并显示导入数与跳过数。
  • 删除、重命名和移除等操作使用悬浮确认气泡。气泡固定在当前视口上方，不改变页面滚动位置；确认或取消后可直接继续原工作流。

Zotero 论文图像

  • 完整图库：点击 Ribbon“素材 → 打开论文图片库”。Zotero 运行且连接就绪时，插件会先请求刷新，再用系统默认浏览器打开 Zotero 生成的同一个完整图库页面。
  • 离线打开：Zotero 未运行但上次生成页面仍存在时，只读打开并提示无法刷新、内容可能不是最新；页面不存在时会提示启动 Zotero 并先打开“全部图库”。
  • 完整图库的卡片、表格、筛选、排序、高清查看、批量选择、刷新、分享、导入和删除均由 Zotero 页面提供，PPT 不复制或重建第二套图库。
  • 右侧快速选择器：从本机共享 SQLite 搜索和预览，即使 Zotero 未打开也可浏览、取色和插入当前图片。
  • 可插入论文参考图像、查看溯源信息、尝试定位原 PDF 或复制溯源 ID。
  • 插件只读共享 SQLite，不读取 Zotero 内部 zotero.sqlite。

配色库

  • 在论文图像卡片点击“设为配色参考”。配色区只显示当前单张图片实际提取出的全部颜色，不固定为 5 色，也不会把多张图的颜色累积到一起。
  • 当前参考图配色未保存时，切换另一张图会显示页面内悬浮确认。取消后仍停留在当前图；确认后才覆盖并读取新图。
  • 确认框可勾选“本次 PowerPoint 会话不再询问”。该选项只保存在当前会话内存，关闭 PowerPoint 后失效，下次打开仍会询问。
  • 点击“保存当前配色”后，当前参考图标记为已保存，此后切换图片不再受未保存状态阻止。
  • 其它来源包括剪贴板、当前页、PowerPoint 主题和用户保存配色。
  • 可预览颜色布局，再选择整体映射；避免只替换少数颜色导致色板失衡。
  • 支持保存、重命名、删除、选择分享和导入配色包。

九、SIMPLEEXPERIMENT 与外部联动

插件可作为本机科研绘图终端接收 SIMPLEEXPERIMENT 请求，并兼容旧版 ZLK Cluster 协议。联动只监听本机回环地址，并使用本机令牌鉴权。

  1. PowerPoint 启动插件后，会在本机应用数据目录发布自动化发现信息和令牌。
  2. SIMPLEEXPERIMENT 通过本机 POST /api/zlk-cluster/plot 提交规范化绘图任务。
  3. 插件复用或创建目标演示文稿并追加原生可编辑图表，不关闭用户已打开的 PowerPoint。
  4. 右侧连接状态仅用于查看和定位，不会自动删除、传输或重绘内容。

十、版本兼容、安装与排障

推荐环境

  • Windows 10 或 Windows 11。
  • 桌面版 PowerPoint 2013、2016、2019、2021、2024 或 Microsoft 365；不支持 PowerPoint 网页版和 macOS 版。
  • Microsoft Edge WebView2 Runtime、.NET Framework 4.8 和 Visual Studio Tools for Office Runtime。
  • 32 位或 64 位 Office 均使用同一 Any CPU 插件；安装包会部署对应架构的本机组件。

安装后看不到变化

  1. 在右侧顶部点击“版本检测”，核对安装版本、提交和构建时间。
  2. 确认 PowerPoint 的“文件 → 选项 → 加载项 → COM 加载项”中已启用 RoughPptAddin。
  3. 如果 PowerPoint 在安装时保持运行，需在方便时由用户自行完全退出并重新打开 PowerPoint；插件不会自动关闭你的窗口。

按钮不可用或参数未显示

  • 简洁模式按选区过滤功能。先选择普通形状、手绘组或特征块，再查看对应参数。
  • 普通对象可转换手绘；手绘组可重绘和调风格；特征块只显示特征块参数。
  • 需要浏览全部专业功能时切换到“完整”模式，或用顶部搜索定位。

科研绘图或 Zotero 未连接

  • 先查看右侧连接状态和中文错误提示。
  • ZLK 只接受本机回环接口和正确令牌；Zotero 图像库必须位于约定的本机共享数据库路径。
  • 连接失败不会阻止普通手绘图形、特征块、模板和本机素材功能。
